# Local Autonomous Coding Platform

This repository is a monorepo scaffold for a local autonomous coding platform based on the provided roadmap.

Quickstart

1. Backend
   - cd backend
   - python -m venv .venv
   - source .venv/bin/activate
   - pip install -r requirements.txt
   - uvicorn app.main:app --reload --port 8000

2. Frontend
   - cd frontend
   - npm install
   - npm run dev

See README in each subfolder for more details.
